PUBLICACIÓN
1. Reemplaza el contenido del repositorio noesor-landing con estos archivos.
2. Conserva la rama main y la publicación desde /(root).
3. Haz commit y push.
4. En Google Search Console agrega sitemap.xml en la sección Sitemaps.

No requiere backend, base de datos ni dependencias externas.
